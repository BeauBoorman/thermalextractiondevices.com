# Jurisdiction Page Quality Status

Project-management classification of every jurisdiction page (last verified 2026-08-09).
This is an editorial workflow label, **not a legal rating**. Statuses:

- **stub-verified** — verified authority, program status, official source, retrieval date; minimal data surface.
- **baseline** — good regulatory information plus a partially mapped data surface.
- **expanded** — deepened profile (regulator history, licensing, testing framework, datasets, ingestion opportunities).
- **data-ingestion-ready** — ingestion adapter exists and is fixture-tested; live content pending a verified sync.
- **deep-ingested** — canonical implementation with published data records in this repository.
- **needs-review** — authoritative verification incomplete; do not publish additional certainty.
