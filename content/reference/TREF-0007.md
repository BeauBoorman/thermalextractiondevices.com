# Michigan Ingestion: Privacy and Excluded-Field Specification
Generated pages from Michigan CRA source data publish only fields on the explicit allowlists below. The machine-readable specification is committed at `data/michigan-cra/privacy-spec.md` and enforced by an automated scan of generated Markdown.

## Excluded Fields and Values

| Category | Examples |
| --- | --- |
| Street addresses | facility premises addresses (not extracted from source PDFs) |
| Owner/officer names | license-registry owner fields (not present in the registry extract) |
| Contact fields | emails, phones (not present in the registry extract) |
| Coordinates | latitude/longitude (not present in the registry extract) |
| Postal codes | ZIP codes are dropped; only municipality and county are published |
| Fields present merely because they exist in source extracts | all non-allowlisted source fields |

## Entity Allowlists

**contaminant**: `name`, `source_name`, `unit`, `matrix`, `action_limit`, `action_limit_source`
**dataset**: `title`, `slug`, `source_url`, `format`, `reporting_period`, `retrieval_date`, `description`, `disclaimer`
**license**: `legal_name`, `license_number`, `license_type`, `program`, `status`, `municipality`, `county`, `license_start_date`, `license_expiration_date`
**organization**: `legal_name`, `license_numbers`, `municipality`
**requirement**: `title`, `citation`, `regulator`, `official_source_url`, `notes`
**safety_advisory**: `title`, `advisory_date`, `canonical_url`, `concern`, `affected_licensees`, `affected_products`
**testing_laboratory**: `legal_name`, `license_number`, `license_type`, `program`, `status`, `municipality`, `accreditation`, `related_jurisdiction`
