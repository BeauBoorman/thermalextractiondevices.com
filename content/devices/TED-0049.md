- 1-year limited warranty on electronics (batteries excluded from normal degradation); RMA requires serial number + scratch-off security code and proof of purchase (per TopGreen support) [^3].
- Opening the device voids warranty [^3].

## Safety Notes

- No dedicated hazard/safety document is published for the V3 Pro; the official listing and support hub cover warranty/RMA terms only (opening the device voids warranty; serial number + security code required for RMA) [^1][^3]. This is a documented absence, not a guarantee of safety.

## Usage Notes

- The official listing markets the device as convection. This archive does not assert a hybrid or convection-dominant classification without an identified source or independent measurement.
- Voltage/power behavior is not published by the manufacturer; the archive does not infer coil temperatures from retail descriptions (see [Vaporizer Heating Architectures guide](../guides/TGDE-0001.md)).
- **Heat-generation tag judgement call.** The official listing states a stainless-steel oven but does not name the element technology. `resistive` is tagged as the closest defensible value, following this archive's own precedent for stainless heating chambers (TinyMight's stainless spiral is tagged `resistive` per TREF-0004); this is an inference, not a manufacturer-stated fact.
