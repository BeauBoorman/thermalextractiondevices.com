## Technical Specifications

| Property | Specification |
| --- | --- |
| Manufacturer | [PAX Labs, Inc.](../manufacturers/TMFR-0022.md) |
| Family | PAX portable line (flagship dual-use) |
| Part Number | PAX does not publish a discrete alphanumeric SKU on the product page; the product is identified by the model designation "PAX Plus" and kit variants (Starter Kit / Complete Kit) [^1] |
| Form Factor | Slim handheld portable; direct-draw mouthpiece (flat and raised mouthpieces included) [^1] |
| Heating Method | Heated-oven conduction with "patented temperature control" (manufacturer phrase); the conduction/convection split is not published for this model [^1] |
| Heat Generation | Electric oven heating element; general `resistive` classification per archive convention [^1] |
| Operation Mode | Session operation with four Experience Modes: Stealth, Efficiency, Flavor, Boost [^1] |
| Temperature Range | 360 °F – 420 °F via the four Experience Modes (Stealth 360 °F, Efficiency 380 °F, Flavor 400 °F, Boost 420 °F base temperatures) [^2] |
| Temperature Control | App-free: long-press the power button (~2 s) to enter mode selection; quick presses cycle modes; LED petal colors indicate the active mode (purple/teal/yellow/red) [^3] |
| Chamber / Load | Flower oven (capacity not stated on official pages); Complete Kit adds a concentrate insert and Half Pack Oven Lid [^1] |
| Power Source | Internal battery; 2+ hours of battery life (manufacturer marketing claim) [^1] |
| Charging | USB cable (connector type not specified beyond "USB Cable" in the box list) [^1] |
| Compatible Media | Dry herb (Starter Kit); dry herb and concentrates (Complete Kit) [^1] |

## Experience Modes

| Mode | Base Temp | Intended Use |
| --- | --- | --- |
| Stealth | 360 °F | Minimizes visible vapor; dims LEDs and vibration |
| Efficiency | 380 °F | Optimizes vapor production; conserves flower |
| Flavor | 400 °F | On-demand flavor-oriented vapor |
| Boost | 420 °F | Maximum vapor production; concentrate use |

Mode temperatures per the manufacturer's journal page [^2]; mode descriptions per the Quick Start Guide [^3].
