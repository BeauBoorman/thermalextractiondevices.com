## Technical Specifications

| Property | Specification |
| --- | --- |
| Manufacturer | [Puffco](../manufacturers/TMFR-0024.md) |
| Family | Proxy modular line (Pipe Kit / Core Kit) |
| Part Number | No discrete alphanumeric SKU is published on the product page; the product is identified by the kit designations "Proxy Pipe Kit" (USD $280) and "Proxy Core Kit" (USD $250) [^1] |
| Form Factor | Modular concentrate vaporizer: electronic Proxy base dropped into a hand-blown borosilicate glass pipe [^1] |
| Heating Method | Electronic heated 3D Chamber ("upgraded 3D Chamber unlocks bigger dabs, better flavor, and reduces splash out" per manufacturer) [^1] |
| Heat Generation | Electric chamber heater; general `resistive` classification per archive convention [^1] |
| Operation Mode | Session (dab) operation; single-click button toggles heat settings; 3-second hold powers on/off [^2] |
| Temperature Control | On-base heat profiles plus Bluetooth Puffco Connect App control of temperature, session time, vapor level, and mood lighting; Vapor Control Mode adjusts cloud size independent of temperature [^1][^2] |
| Chamber | 3D Chamber with Joystick Cap (kit contents per owner's manual: Proxy base, 3D Chamber, Joystick Cap, Oculus carb cap on some kits, glass pipe, loading tool, cotton swabs, USB-C cable, carry case) [^2] |
| Power Source | Internal battery; ≈15 dabs per charge depending on heat settings [^1] |
| Charging | USB-C (per kit contents); ≈2 hours full charge; usable while charging if some charge remains [^1][^2] |
| Battery Indication | LED glow: Green (full), Orange (half), Red (low); LED bar dimmable via four button clicks [^2] |
| Compatible Media | Cannabis concentrates [^1] |

## Safety Notes

- Not for use with tobacco or nicotine-containing liquids (manufacturer platform warning) [^1].
- Electronic base: avoid liquid ingress; glass pipe is a burn hazard until cooled [^2].
